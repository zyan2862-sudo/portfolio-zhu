# Yan Zhu — Sport × Research × Field

Trilingual personal portfolio for international sport projects, sport
management research, and event operations.

## Preview

Open `index.html` in a browser. No installation or build step is required.

## Edit content

All Chinese, Japanese, and English content is stored in `portfolioData.js`.
Layout and reusable render functions are in `app.js`; visual design is in
`style.css`.

## Replace images

Add images to the `assets` folder and reference them from `portfolioData.js` or
`index.html`. Always provide meaningful `alt` text.

## Publish on GitHub Pages

Upload all files and the `assets` folder to the repository. In GitHub, choose
**Settings → Pages → Deploy from a branch → main → / (root)**.

## Contact form

The form opens the visitor's email application and sends to the address stored
at the top of `portfolioData.js`. It does not store visitor data.
